# Mensageiro Engineering Lab

Este repositório representa a evolução técnica do projeto **Mensageiro**, originalmente desenvolvido como parte de um desafio técnico.

Aqui utilizo o projeto como laboratório para aprofundar conhecimentos e aplicar melhorias , boas práticas e maior entendimento dos conceitos utilizados e por ae vai

> O projeto original enviado para avaliação permanece inalterado.  
> Este repositório é uma evolução posterior com fins de estudo e aperfeiçoamento técnico.

---

# Objetivo

Transformar um projeto funcional em um projeto mais estruturado, escalável e próximo de um ambiente profissional, só vai faltar receber abertura de chamados para 'resolver' as buchas..
